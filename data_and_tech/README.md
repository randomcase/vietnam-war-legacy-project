# data_and_tech/

The numbers, as data, so they can be computed from and argued with.

| file | what | source |
|---|---|---|
| `bomb_tonnage.csv` | US tonnage on Indochina by year, thousands of tons | USAF Historical Research Agency tables; approximate |
| `yard.json` | the six hull classes: tons, cost in steel, rate | the same rows the idle game and the Scala/Java shipyards read |
| `fleet.json` | written by `src/Ships.scala` on each run | generated; do not edit |
| `uxo_drone_tech.md` | how ordnance is found now: LiDAR, thermal, magnetometer, GPR, THOR, the villagers | MAG, HALO, UXO Lao |
| `flight_deck_jerseys.txt` | the colour lexicon and the Ouija board | NHHC |
| `night_recovery.txt` | a **simulated** night recovery at Yankee Station, labelled as such | invented; form only |
| `asw_screen.md` | the three rings around a carrier | Friedman, *US Aircraft Carriers* |
| `carriers.md` | Constellation vs Enterprise; Omaha vs Missouri vs Constellation; who built them | DANFS |

**Wanted.** The tonnage by year from a primary table rather than a secondary summary; the CSV says "approximate" because it is. A sortie count to go with the tonnage. Cost figures for the yard in dollars of the day, so the game's "steel" can be checked against a shipbuilding budget. Anyone who adds a column must add its source to this table.
